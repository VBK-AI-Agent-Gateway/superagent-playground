# 轻量项目管理页（零构建）

面向小团队（3~10 人）的纯前端单页应用：**任务看板 + 团队成员列表 + 活动时间线**，三个板块数据同源联动。

## 使用方法

直接双击 `index.html` 即可在 Chrome / Edge / Firefox 最新版中打开，**无需服务器、无需构建、无任何外部网络资源**。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构：顶栏、看板、成员列表、时间线、新增表单与提示条 |
| `styles.css` | 原生 CSS 样式：CSS 变量、Grid/Flex 布局、响应式断点 |
| `app.js` | 全部业务逻辑：状态与持久化、任务/成员增删移、三大板块渲染与事件绑定 |
| `data.js` | 初始 mock 数据与常量（列定义、优先级、统计口径、存储键） |

## 功能一览

- **任务看板**：三列（待办 / 进行中 / 已完成）；卡片含标题、负责人、优先级、截止日期；支持新增任务、在列间移动任务（拖拽或「推进 / 退回」按钮）、删除任务；逾期任务高亮。
- **团队成员**：首字母圆形色块头像占位、姓名、角色、在办任务数；支持新增 / 移除成员。
- **活动时间线**：按时间倒序记录任务创建、任务状态变更、成员增删，每条含可读时间戳与描述。

## 数据联动与持久化

三个板块都从同一份内存状态 `state` 派生，任何操作只修改 `state` 再统一 `commit()` 重绘，
因此移动任务后：任务状态、负责人「在办任务数」、活动时间线三处会同时更新。

- 数据保存在浏览器 `localStorage`（键名 `pm-board-state-v1`），**刷新页面后保留**；
- 顶栏「重置演示数据」按钮可清空本地数据并恢复初始 mock 数据；
- 若浏览器禁用本地存储（如隐私模式），页面仍可使用，只是修改不会跨刷新保留，并会给出提示。

## 约定

- 统计口径：**在办任务数 = 该成员名下「待办 + 进行中」的任务数**（定义见 `data.js` 的 `ACTIVE_STATUSES`）。
- 为保证数据一致，**仍有在办任务的成员不可移除**，需先改派或完成其任务。
- 技术约束：仅原生 HTML / CSS / ES6 JavaScript，普通 `<script>` 标签加载（非 ES Module），保证 `file://` 下直接可用。
