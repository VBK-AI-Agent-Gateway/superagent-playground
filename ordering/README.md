# 蜀香居 · 中餐点餐（第一版）

纯前端单页点餐演示：**HTML + CSS + JavaScript**，无框架、无构建步骤、无后端，所有菜品与订单数据都在本地模拟。

## 打开方式

三种方式任选其一：

1. **直接双击** `index.html`，用浏览器打开即可（无需服务器）。
2. 或者起一个本地静态服务器（推荐，行为与部署环境一致）：

   ```bash
   cd ordering
   python3 -m http.server 8000
   # 浏览器访问 http://127.0.0.1:8000
   ```

3. 或者用 Node：

   ```bash
   npx serve ordering
   ```

## 功能

| 功能 | 说明 |
| --- | --- |
| 菜单浏览 | 顶部 5 个分类标签：凉菜 / 热炒 / 主食 / 汤羹 / 饮品，可横向滑动 |
| 菜品卡片 | 名称、描述、价格、月售、辣度（🌶）、CSS 渐变图片占位（不使用任何外部图片） |
| 内置菜品 | 26 道模拟菜品（凉菜 5、热炒 10、主食 5、汤羹 3、饮品 3） |
| 购物车 | 卡片上的「加入 / +/−」加减数量，右上角购物车按钮打开浮层，实时明细与总价 |
| 下单 | 选择桌台（1–20 号桌）→ 提交 → 订单确认页 |
| 订单确认 | 订单号、桌台、下单时间、菜品清单与数量、合计金额、预计出餐「约 15 分钟」 |
| 再来一单 | 确认页一键清空并回到菜单 |

## 视觉风格

中式暖色调：宣纸白背景（带极淡斜纹质感）+ 朱砂红主色 + 墨色文字，扁平化圆角卡片。
宽度 ≤ 720px 时切换为紧凑双列布局，购物车抽屉变为全屏；已适配手机竖屏（390×844 无横向滚动）。
分类标签栏在 360px 等极窄屏上可横向滑动（标签总量略宽于视口），页面本身不产生横向滚动。

## 技术说明

- **无外部依赖**：不引用任何 CDN、字体或图片资源，离线也能打开。
- **图片占位**：每道菜用一条 CSS 渐变（8 种配色）+ 一个汉字构成占位图。
- **可访问性**：按钮带 `aria-label`，分类标签与桌台为 `aria-pressed` / `role="radio"`，支持键盘 `Esc` 关闭购物车抽屉。
- **调试接口**：`window.__ORDERING__.getState()` 可读取当前分类、购物车、桌台与订单快照，便于自动化验证。

## 不在本版范围

后端接口、真实支付、用户登录、订单持久化、多语言。第一版仅覆盖 issue #6 描述的功能。
