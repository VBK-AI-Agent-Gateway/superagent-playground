# 荣威 RX5 · 网页版智能座舱（roewe-cockpit）

一个**零构建**的荣威 RX5 车机座舱演示：纯 HTML + CSS + 原生 JS（Vue 3 全局构建），
双击 `index.html` 即可运行，无需 npm / node / 打包工具。

- 设计分辨率：**1080 × 1920**（竖屏 9:16），基于 `rem`（`--root-font: 9.259259vw`）+ `vw` 自适应缩放，
  在任意窗口尺寸下等比呈现车机屏幕，超出部分自动黑边。
- 主题：深色座舱（默认）/ 浅色座舱，一键切换。
- 数据：全部为内置模拟数据（天气、路况、歌曲、蓝牙设备、停车场充电桩等），不发任何请求。

## 一、快速开始

```bash
# 方式 1：直接打开（推荐，无任何依赖）
open roewe-cockpit/index.html          # macOS
xdg-open roewe-cockpit/index.html      # Linux
start roewe-cockpit\index.html         # Windows
```

```bash
# 方式 2：本地静态服务器（高德地图 / 语音识别等需要 http(s) origin 时更稳妥）
cd roewe-cockpit && python3 -m http.server 8080
# 浏览器访问 http://127.0.0.1:8080/
```

> 直接以 `file://` 打开时，浏览器会限制麦克风（Web Speech API）与部分 CDN 脚本；
> 此时语音助手自动降级为**文字模拟对话**，地图自动降级为**内置示意地图**，功能仍完整可用。

## 二、配置高德地图 Key

1. 到 [高德开放平台](https://lbs.amap.com/) 创建应用，申请 **Web 端（JS API）** Key。
2. 编辑 `roewe-cockpit/config.js`：

```js
window.ROEWE_CONFIG = {
  amap: {
    key: '你的高德 Web 端 Key',
    securityJsCode: '你的安全密钥',   // 2021-12-02 之后申请的 Key 必填
    version: '2.0',
    timeout: 6000                     // 加载超时（毫秒），超时自动回退
  },
  ...
};
```

3. 刷新页面：导航页右上角引擎标识变为 **高德 · 在线**，即接入成功。

**回退行为**：未填 Key、Key 无效、网络不可达或加载超时，导航页自动使用**内置 SVG 示意地图**
（含道路、路线、车道引导、路况与沿途充电桩），并在界面下方给出提示，功能不中断。
高德接入后同样保留车道引导、实时路况、路线规划与充电站 UI。

## 四、四条强制安全规则

1. **挡位状态机 · 行车娱乐限制**
   `D` 挡且车速 > 5 km/h 时，娱乐类页面（多媒体、360 全景）被拦截，
   顶部状态栏与页面内同时显示「**行车中，娱乐功能已限制**」；
   切回 `P` 挡后车速归零，全部功能立即解锁。
2. **轻量非阻塞提示**
   所有提示均为右下/顶部浮层 toast，**不遮挡**导航、车速、挡位与报警信息；
   关键驾驶信息（速度、挡位、雷达报警）在受限状态下始终可见。
3. **车规级过渡动画**
   页面采用方向感知的滑入 / 缩放过渡（前进入场、返回反向），卡片分级错落入场，
   统一 `cubic-bezier(0.22, 0.61, 0.36, 1)`，无硬切；同时尊重 `prefers-reduced-motion`。
4. **行车状态模拟器**
   位于「设置」页首屏。

## 五、行车状态模拟器用法（交付验证依赖它）

打开 **Dock → 设置**，页面顶部即为模拟器：

| 控件 | 作用 |
|------|------|
| `P 驻车` | 挂 P 挡，车速归零，解除全部娱乐限制 |
| `D 前进` | 挂 D 挡，车速自动抬升至 8 km/h，导航优先展示 |
| 车速滑块 | 0 – 120 km/h 任意拖动；阈值 **5 km/h** |
| `0 / 30 / 60 / 90` | 车速快捷设定 |

**验证步骤**

1. 点 `D 前进` → 车速 > 5 km/h。
2. 点 Dock 的「多媒体」或「全景」→ 被拦截，提示「行车中，娱乐功能已限制」，
   底部 Dock 上这两项出现锁标，同时车速、挡位、报警仍清晰可见。
3. 点 `P 驻车` → 限制解除，娱乐页面可正常进入。
4. 首页在 D 挡时导航卡片置顶，并有「即将开始导航」箭头提示。
5. 点状态栏右侧太阳/月亮图标可切换深浅主题，所有模块同步换肤。

## 七、浏览器兼容

| 浏览器 | 说明 |
|--------|------|
| Chrome / Edge 90+ | 推荐，语音识别与播报完整可用 |
| Safari 15+ | 可用；语音识别需用户手势触发 |
| Firefox | 无 Web Speech 识别，自动降级为文字模拟对话 |

> 高德地图、Three.js、Vue、Tailwind 均通过 CDN 加载；断网时 Vue 会尝试备用 CDN，
> 地图与 3D 车模自动降级为内置实现，其余功能不受影响。
