# 荣威 RX5 网页版车机座舱（rowe-cockpit）

面向 SAIC 荣威 RX5（目标平台：斑马 / 洛神车机）的 OEM 竖屏座舱前端。
基准分辨率 **1080 × 1920（10.4" 竖屏，9:16）**，卡片式布局参考理想 / 小鹏的座舱设计语言。

## 快速开始

**零构建，开箱即跑。** 不需要 npm、Node 或任何打包步骤：

1. 双击 `index.html`（或拖入浏览器窗口）即可运行。
2. 全部依赖已本地化到 `vendor/`，**联网与否都能启动**：
   - `vendor/vue.global.prod.js` — Vue 3 运行时（全局构建）
   - `vendor/tailwindcss.js` — Tailwind CSS 浏览器构建

> 建议使用 Chromium 内核浏览器（Chrome / Edge）以获得最佳缩放与语音支持。
> 以 `file://` 直接打开时，高德地图与语音识别会受限，属预期行为（见下方降级说明）。

目录结构：

```
rowe-cockpit/
├── index.html           # 唯一入口（脚本加载顺序在此声明）
├── config.js            # 运行时配置：高德密钥、车辆信息、唤醒词、默认值、模拟器
├── css/
│   ├── base.css         # 设计令牌（深/浅色）、重置、亮度遮罩
│   ├── layout.css       # 1080×1920 基准的 rem/vw 缩放与骨架布局
│   ├── components.css   # 状态栏 / 卡片 / Dock / 浮层 / 基础控件
│   ├── modules.css      # 八个模块的专属样式
│   └── animations.css   # 页面过渡与动效（车规级）
├── js/
│   ├── data/mock.js     # 全部模拟数据（车辆、空调、媒体、天气、导航、泊车、设置）
│   ├── store/
│   │   ├── state.js     # 全局响应式状态 + localStorage 持久化
│   │   └── safety.js    # 挡位状态机、娱乐限制、路由与过渡选择
│   ├── core/
│   │   ├── voice-registry.js  # 「可见即可说」指令注册表与模糊匹配
│   │   ├── voice.js           # Web Speech API 封装 + 文本模拟降级
│   │   ├── map-loader.js      # 高德 JS API 2.0 加载与离线降级
```

## 配置高德地图密钥

高德 JS API 2.0 的密钥在 **`config.js`** 中填写，无需改动其他文件：

```js
window.COCKPIT_CONFIG = {
  // 高德开放平台（https://console.amap.com）申请的 Web 端（JS API）密钥
  amapKey: '',                 // ← 填入你的 Key
  amapSecurityJsCode: '',      // ← 若启用了「安全密钥」则一并填入
  amapVersion: '2.0',
  amapPlugins: ['AMap.Driving', 'AMap.Geolocation', 'AMap.PlaceSearch', 'AMap.AutoComplete'],
  ...
};
```

- **留空或加载失败时的行为**：地图区域自动切换到内置的**离线降级地图**（矢量路网示意图 + 匀速流动的路线动画），
  路线规划、车道级引导、路况列表、充电/加油搜索等 UI 全部照常可交互。
  降级时地图左下角会显示来源提示，不会抛出控制台错误。
- 若配置了安全密钥，加载器会在引入 SDK 前设置 `window._AMapSecurityConfig`。
- 生产环境请不要把密钥写进可公开访问的静态文件——建议由服务端签名或代理转发。

## 八个模块

| # | 模块 | 入口 | 能力 |
|---|------|------|------|
| ① | **主页** | Dock「主页」 | 常驻 Dock；3D 车模卡片（Three.js，超时回退 SVG）；实时车速 / 电量 / 续航 / 油量；时钟 + 天气卡片；**D 挡自动切换为导航优先卡片**，P 挡恢复完整卡片布局 |
| ② | **导航** | Dock「导航」 | 高德地图或离线降级图；3 条可选路线（距离 / 时长 / 路况 / 收费）；车道级引导条；实时路况列表；充电桩 / 加油站搜索与一键导航；缩放与回中 |
| ③ | **空调** | Dock「空调」 | 双温区温度（16–30 ℃，0.5 步进）与同步；风量 0–7 档；内循环、A/C、自动、前 / 后除霜；左右座椅加热 0–3 档 |
| ④ | **媒体** | Dock「媒体」 | 在线 / 本地 / 电台 / 蓝牙四种音源；播放控制、进度拖动、音量滑块与静音；曲目列表；蓝牙设备、最近通话、联系人、一键拨号与挂断 |
| ⑤ | **车辆** | Dock「车辆」 | 灯光（近光 / 示宽 / 氛围灯等）、后视镜（自动折叠 / 倒车下翻 / 加热）、门锁（行车落锁 / 自动落锁 / 儿童锁）、天窗、驾驶模式（舒适 / 运动 / 经济 / 雪地）、倒车影像模拟窗口（动态轨迹线 + 亮度） |
| ⑥ | **语音** | Dock「语音」/ 悬浮球 | 唤醒词【你好，斑马】【你好荣威】；连续对话（默认 8 秒窗口）；「可见即可说」——所有可点击控件都已注册指令；指令日志与示例；Web Speech API 不可用时提供文本模拟输入 |
| ⑦ | **360 全景** | Dock「全景」 | 720×520 全景画布，按视角绘制雷达距离、侧向间距、障碍物方位与倒车轨迹线；四路视角切换；拖拽环视与自动巡览 |
| ⑧ | **设置** | Dock「设置」 | 亮度（20–100，自动亮度开关）、深色 / 浅色主题、WiFi 开关与网络列表（含模拟连接）、蓝牙开关与解除配对、OTA 版本与检查更新、存储占用、语言、关于本机；内置驾驶状态模拟器入口 |

## 安全规则（最高优先级）

1. **挡位状态机**
   - **D 挡（或车速 ≥ 5 km/h，速度阈值见 `config.js` 的 `simulator.drivingSpeedThreshold`）**：锁定娱乐类视图——媒体、360 全景、泊车辅助。点击被锁定的 Dock 项不会跳转，而是给出温和提示 **「行车中，娱乐功能已限制」**；若已处于娱乐视图，切到 D 挡会**自动引导回主页**。
   - **P 挡**：解锁全部功能。
   - 该状态机同时是**悬停覆盖层**的前提：只有非行车态才允许展开全屏面板。
2. **轻量覆盖层**
   - 浮动面板（语音、模拟器、灯光面板、提示条）都是**非阻塞的局部浮层**，不使用全屏遮罩。
   - 顶部状态栏常驻且层级最高：**车速、挡位、告警信息在任何视图与浮层下始终可见**。
3. **平滑过渡**
   - 页面切换按方向选择推入 / 返回 / 交叉淡入动画（`css/animations.css`），无硬切。
   - 行车态自动关闭装饰性循环动画，降低视觉干扰。
   - 遵循 `prefers-reduced-motion`。
4. **驾驶状态模拟器**
   - Dock 右侧的虚线按钮（或设置页「驾驶状态模拟器」）打开模拟器面板：
     **P / R / N / D** 四挡切换、**0–180 km/h** 车速滑块、一键「立即行车」/「立即驻车」。
   - 交付验证依赖它：切到 D 挡或把车速拉到 5 km/h 以上，即可观察娱乐限制生效。

## 自检清单

在浏览器中打开 `index.html` 后：

- [ ] 八个模块均可从 Dock 进入，且各自可交互（空调调温、媒体播放、车辆开关等）。
- [ ] 打开模拟器切到 **D** 挡：娱乐类 Dock 项出现限制标记，点击弹出「行车中，娱乐功能已限制」。
- [ ] 车速拉到 5 km/h 以上同样触发限制；切回 **P** 挡自动恢复。
- [ ] 设置页切换深色 / 浅色主题，页面配色即时变化且被记住（刷新后保持）。
- [ ] 亮度滑块生效，可整体压低屏幕眩光。
- [ ] 顶部状态栏在任意视图与浮层下都能看到车速与挡位。
- [ ] 页面切换为平滑动画，无白屏硬切。
- [ ] 控制台无报错（未配置高德密钥时也不应有报错，此时导航走离线降级）。

## 其他说明

- **全部数据为模拟数据**，不连接任何真实车辆总线；车速、电量、油量等仅用于演示。
- 车辆信息、唤醒词、默认主题 / 亮度 / 音量、模拟器初值都可以在 `config.js` 中修改。
- 主题、亮度与挡位会写入 `localStorage`（键名 `rx5.theme` / `rx5.brightness` / `rx5.gear`）。
- 布局以 1080×1920 为基准按视口宽度等比缩放；横屏 / 宽屏下居中显示竖屏画布，属于非目标平台的可用性降级。
