# 朱砂小馆 · 中餐点餐系统（ordering/）

一个**零构建**的中式餐厅扫码点餐网页应用：双击 `index.html` 即可在浏览器中运行，
不需要 npm、node 或任何打包步骤，仓库中也不提交 `node_modules`。

## 使用方法

1. 直接**双击 `ordering/index.html`**，用浏览器（Chrome / Edge / Safari / Firefox）打开即可。
2. 或者用任意静态服务器访问该目录，例如：

   ```bash
   # 在仓库根目录执行，任选一种
   python3 -m http.server 8000
   npx serve .          # 若本机已装 Node，仅为可选方式
   ```

   然后浏览 <http://localhost:8000/ordering/>。
3. 按屏幕提示完成点餐：**选桌台 → 选菜加入购物车 → 提交订单 → 查看订单确认**。

> 全部资源均为本地文件（含 `vendor/vue.global.prod.js`），运行时不请求任何 CDN，
> 因此离线环境同样可用。

## 功能列表

- **菜单浏览**
  - 五个分类标签：凉菜 / 热炒 / 主食 / 汤羹 / 饮品，另有「全部」分段浏览。
  - 菜品卡片展示：菜名、价格、月售份数、辣度标记（🌶 微辣 / 中辣 / 特辣，0 级显示「不辣」）。
  - 纯 CSS 渐变占位图，不依赖任何图片资源。
  - 分类标签带菜品数量角标；支持按菜名与口味关键字实时搜索。
- **购物车**
  - 实时行项目：菜名、单价、数量与行小计。
  - 数量 `+ / −` 增减，减到 0 自动移除，也可单行删除或一键清空。
  - 合计金额实时更新（以「分」为单位计算，避免浮点误差）。
  - 徽标计数显示商品总件数；桌面端为右侧常驻侧栏，移动端为底部吸底栏 + 上滑抽屉。
- **点餐流程**
  - 桌台选择：大厅 A 区 8 桌 + 包厢 B 区 8 桌，共 **16 桌**，标注人位数。
  - 未选择桌台时，提交按钮保持**禁用**状态并给出提示；选桌后可提交。
  - 订单确认页展示：**订单号**、桌台信息、下单时间、**菜品清单**（含数量与行小计）、
    **合计金额**、**预计等待时间**（按件数估算，12–40 分钟）。
  - 支持「再来一单」把上一单菜品重新加入购物车，或返回菜单继续点餐。
- **模拟数据**
  - 菜品共 **24 道**，集中在 `js/data/menu.js`，覆盖全部五个分类。
  - 每个菜品包含名称、价格、月售、辣度、简介、标签与渐变色，便于自行增删。
- **界面与适配**
  - 配色：宣纸白 `#F7F3E8` + 朱砂红 `#9E2B25` + 墨色 `#26221E`，配以篆刻式方形图标。
  - 响应式：桌面端 1440 宽（三至四列卡片网格 + 右侧栏）、移动端 390 宽（单列 + 吸底购物车）。
  - 两档视口均无横向滚动；下单、增减等操作有轻提示反馈。

## 目录结构

```
ordering/
├── index.html                  # 唯一入口，双击即可运行
├── css/
│   ├── base.css                # 设计变量、重置、按钮/徽标/价格/辣度/步进器
│   ├── menu.css                # 菜单浏览：餐厅信息、搜索、分类标签、菜品卡片
│   ├── cart.css                # 购物车、桌台选择、订单确认页
│   └── responsive.css          # 1440 桌面 / 390 移动两档响应式
├── js/
│   ├── data/
│   │   └── menu.js             # 模拟数据：分类、24 道菜品、16 张桌台
│   ├── store.js                # 全局状态：购物车、桌台、下单、金额计算
│   ├── components/
│   │   ├── common.js           # 通用组件：辣度标记、渐变占位图、步进器、空状态
│   │   ├── menu.js             # 模块一：菜单浏览
│   │   ├── cart.js             # 模块二：购物车
│   │   └── order.js            # 模块三：桌台选择 + 订单确认
│   └── app.js                  # 应用入口：注册组件、挂载根实例
├── vendor/
│   └── vue.global.prod.js      # Vue 3.4.21 生产版运行时（本地化，无 CDN 依赖）
└── README.md
```

## 数据与扩展

- 修改菜品或桌台：编辑 `js/data/menu.js` 中的 `DISHES` / `TABLES` 数组即可，界面自动更新。
- 新增分类：在 `CATEGORIES` 中追加一项，并在菜品上引用其 `id`。
- 新增页面模块：在 `js/components/` 下新建文件，并在 `index.html` 中按顺序引入脚本。

## 说明

- 本目录为纯静态交付物，不含任何构建配置；`vendor/` 中的 Vue 运行时仅作为普通脚本加载。
- 订单号、预计等待时间为本地模拟生成，不涉及后端接口与真实支付。
