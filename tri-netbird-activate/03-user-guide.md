# NetBird 客户端接入指南（零技术版）

> 照着做就行，**一共三步，约 5 分钟**。遇到看不懂的，直接找 IT 同事。

---

## 一、先装客户端

点下面的链接，下载你电脑/手机的版本，**一路点「下一步」装完即可**：

| 你的设备 | 下载地址 |
|---|---|
| **Windows** | https://github.com/netbirdio/netbird/releases （选 `netbird_*_windows_amd64.exe`） |
| **macOS** | https://github.com/netbirdio/netbird/releases （选 `netbird_*_darwin_universal.pkg`） |
| **Linux** | https://github.com/netbirdio/netbird/releases （选 `netbird_*_linux_amd64.deb`） |
| **Android** | 应用商店搜 **NetBird**，或 https://play.google.com/store/apps/details?id=io.netbird.client |
| **iOS / iPad** | App Store 搜 **NetBird**，或 https://apps.apple.com/app/netbird/id6475835921 |

官方安装总入口（不确定就点这里）：**https://docs.netbird.io/how-to/installation**

> 装的时候如果系统问「是否允许此程序修改设备」，选**允许**。这是 VPN 类软件的正常要求。

## 二、三步接入

### 第 1 步：打开客户端

装完后启动 NetBird。它会显示一个还没连接的状态（灰色/未连接）。

### 第 2 步：填管理地址

在客户端的设置里找到 **Management URL / 管理地址**，填入：

```
https://5.189.129.216:8443
```

**命令行用户**（Linux / macOS 终端）也可以直接一条命令搞定：

```bash
netbird up --management-url https://5.189.129.216:8443
```

### 第 3 步：粘贴 Setup Key

客户端里点 **Connect / 连接**，会弹出让你输入 **Setup Key** 的框。

把管理员发给你的那串 key（形如 `XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX`）**整段复制粘贴**进去，确认。

> ⚠️ Setup Key 是**通行证**，不要发到群里、不要截图发人。丢了找管理员重新发一句。

---

## 三、怎么知道成功了

两个办法，任选：

**办法 1：看客户端**

命令行执行：

```bash
netbird status
```

看到 **`Connected`** 就是成功了。

**办法 2：让管理员看后台**

告诉管理员你的设备名，管理员在 NetBird 后台（Dashboard）的 **Peers** 页面能看到你这台设备**多出来一个新条目**，就是接入成功。

## 四、首次连接可能弹的提示（正常现象，不用怕）

我们的服务器用的是**自签名证书**，所以第一次连接时系统会「不认识」这台服务器，弹窗警告。这是**预期内的**，按下面处理：

### Windows 上

- 可能弹窗说「**无法验证此网站的身份**」或「**证书不受信任**」。
- 如果客户端里出现 **Trust / 信任 / 继续** 之类的按钮，**点它**。
- 如果是浏览器打开的后台页面弹「**你的连接不是私密连接**」，点 **高级 → 继续前往 5.189.129.216（不安全）** 即可（这条只针对我们这台内网服务器）。

### macOS 上

- 可能弹窗说「**无法验证服务器身份**」或要求把证书加入信任。
- 在客户端弹窗里点 **Trust / 信任 / Continue（继续）**。
- 如果提示要输入**开机密码**，输入你的 Mac 登录密码即可（系统在把它加入信任列表）。
- 也可以在「钥匙串访问」里找到该证书，右键 → 显示简介 → 信任 → 选「始终信任」。

### 手机（Android / iOS）

- 一般会弹「**是否信任此连接**」，点 **信任 / 继续**。

> 这些提示**只在第一次**出现；信任之后以后连接就静默了。
> 如果**反复**弹同一个提示、点信任也没用，别自己折腾，把截图发给管理员。

## 五、连上了能干什么 / 连不上怎么办

**连上后**：你会像在同一个办公室局域网里一样，能直接访问公司内部系统（具体能访问哪些，问管理员）。

**连不上时自查三件事**：

1. 客户端里**管理地址**有没有填错（必须是 `https://5.189.129.216:8443`，注意是 **https**、端口 **8443**）。
2. **Setup Key** 有没有复制全（前后不要多空格，中间不要断行）。
3. 网络是否正常（能打开普通网页）。

三条都对了还是连不上 → **把客户端的报错截图发给管理员**，写清楚你的设备系统（Windows 10 / macOS 14 / 安卓 …）。
