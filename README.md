# CRM 客户关系管理系统

一个**纯静态、零依赖、零构建**的 CRM 单页应用：原生 HTML + CSS + ES6 模块，数据保存在浏览器
`localStorage`，支持一键 JSON 导出 / 导入。可直接用 GitHub Pages 或任意静态服务器托管。

## 快速开始

由于使用原生 ES6 模块（`<script type="module">`），必须通过 HTTP 协议访问，**不能**直接双击
`index.html`（`file://` 会被浏览器的模块 CORS 策略拦截）。

```bash
# 在项目根目录任选一种：
python3 -m http.server 8080
# 或
npx serve .
```

然后打开 <http://localhost:8080/>，默认进入仪表盘。

## 目录结构

```
index.html              页面外壳：模块入口、#app / #view 挂载点、#toast-host
css/style.css           全部样式：布局、卡片、看板、图表、模态框、时间线、响应式与深色主题
js/app.js               应用入口：初始化数据、注册路由、渲染导航外壳、导出/导入/设置等全局操作
js/router.js            Hash 路由：#/path、:param 匹配、查询参数解析、导航钩子
js/store.js             数据层：localStorage 持久化、CRUD、状态流转、统计指标、JSON 导出/导入
js/ui.js                通用 UI 组件：卡片、徽章、按钮、表单字段、弹窗、分页、图表、跟进时间线
js/seed.js              可选示例数据（仅点击仪表盘「载入示例数据」时写入）
js/views/dashboard.js   仪表盘：KPI 卡片 + 线索分布 / 新增趋势 / 阶段金额 / 线索漏斗图表
js/views/customers.js   客户管理：列表（搜索/筛选/排序/分页）、详情、联系人、创建与编辑
js/views/leads.js       线索管理：列表、状态流转、一键转化为客户、详情
js/views/deals.js       商机管理：阶段看板 + 列表双视图、卡片上的阶段切换按钮、金额合计
js/views/followups.js   跟进记录：全量倒序时间线、按对象/日期筛选、快速新增
```

## 功能地图

| 路由 | 说明 |
| --- | --- |
| `#/dashboard` | 默认视图。客户总数、线索总数、本月新增、成交金额等 KPI，以及线索状态分布、近 6 个月新增趋势、商机阶段金额、线索漏斗与最近跟进。 |
| `#/customers` | 客户列表：关键字搜索、状态/等级/来源筛选、排序、分页；支持创建、编辑、删除。 |
| `#/customers/:id` | 客户详情：基本信息、联系人、关联商机、跟进记录。 |
| `#/leads` | 线索列表：状态流转（新建 → 跟进中 → 已转化 / 已流失）与「一键转化客户」。 |
| `#/leads/:id` | 线索详情：信息、流转进度、转化结果、关联商机、跟进记录。 |
| `#/deals` | 商机看板（默认）与列表视图切换；看板按六个阶段成列，卡片上可直接切换阶段，列头显示阶段金额合计。 |
| `#/deals/:id` | 商机详情：金额、预计成交日期、阶段进度、关联客户/线索、跟进记录。 |
| `#/followups` | 全部跟进记录，按时间倒序，可按对象类型、具体对象与日期区间筛选。 |

## 数据模型

所有数据保存在 `localStorage`：

| 键 | 内容 |
| --- | --- |
| `crm.data.v1` | `{ customers, leads, deals, followups, version }` |
| `crm.settings.v1` | `{ operator }` —— 跟进记录默认操作人 |
| `crm.data.v1.undo` | 最近一次「清空 / 覆盖导入」前的快照，可在设置中撤销 |

- **客户**：名称、行业、等级（A/B/C）、状态（潜在/合作中/暂停/已流失）、来源、联系方式、地址、
  负责人、备注、联系人数组。
- **线索**：联系人姓名、公司、电话、邮箱、来源、状态（新建/跟进中/已转化/已流失）、负责人、备注，
  转化后写入 `customerId` 建立关联。
- **商机**：名称、关联客户或线索、金额、阶段（初步接洽/需求确认/报价/谈判/赢单/输单）、
  预计成交日期、负责人、备注。
- **跟进记录**：所属对象（客户/线索/商机）、内容、操作人、时间戳。

删除客户或商机会级联清理其关联的跟进记录。

## 数据导入 / 导出

顶栏与侧栏都提供 **导出 JSON**（下载 `crm-backup-YYYY-MM-DD.json`，浏览器禁止下载时改为弹窗展示
可复制的 JSON）与 **导入 JSON**（先校验结构，可选择覆盖或按 id 合并；覆盖前自动保存撤销快照）。

## 环境与限制

- 浏览器要求：支持 ES6 模块与 `localStorage` 的现代浏览器（Chrome / Edge / Firefox / Safari）。
- 无框架、无 UI 库、无 CDN、无网络请求；图表为手写 CSS / SVG。
- 无后端、无账号体系、无多端同步；数据仅存在于当前浏览器，清除浏览器数据会丢失，请定期导出备份。
- 已验证布局：1280px 与 375px 宽度下无横向溢出。
